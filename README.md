# ScholarForge Suite: Unified Scholarly Intelligence Platform

**ScholarForge Suite** is a unified, state-of-the-art academic research platform that integrates federated multi-registry extraction, PRISMA 2020 systematic review tracking, scholarly manuscript grounding, and pre-submission bibliography integrity auditing.

Developed by **Professor Babu George**.

---

## 🏛️ The 4 Pillars of ScholarForge Suite

### 1. 🔍 Literature & Federated Multi-Source Extraction
- **Concurrent Federated Queries**: Searches OpenAlex, Europe PMC / PubMed Central, Crossref, Semantic Scholar Graph API, and arXiv Open Archive simultaneously with real-time deduplication.
- **PRISMA 2020 Protocol & Diagram**: Real-time identification counts per database, screening attrition tracking (preprints, missing abstracts, citation thresholds), and 1-click export of publication-ready PRISMA methodology prose.
- **Academic Retraction Sentinel**: Cross-checks Europe PMC, PubMed, and Crossref to alert researchers of retracted publications before citing.
- **Dataset Scientometrics**: Computes dataset $h$-index, citation velocity, citation impact tiers (`🔥 Highly Cited`, `⭐ Influential`, `🌱 Emerging`), and automatic methodology tagging (`#RCT`, `#MetaAnalysis`, `#Survey`).

### 2. 🛒 Universal Research Cart & Scientometrics
- **Persistent Multi-Search Basket**: Accumulates papers across searches, literature extractions, and manual lookups.
- **COinS (ContextObjects in Spans)**: OpenURL Z39.88 tags for 1-click import into Zotero Connector, Mendeley Web Importer, and EndNote.
- **Multi-Format Exports**: Microsoft Word (`.doc`), `.ris`, `.bib`, and Open Access PDF link lists.
- **7 LLM & NotebookLM Prompts Suite**: One-click prompt bundles for literature matrices, research gaps, methodology comparisons, and full manuscripts.

### 3. ✍️ Manuscript Studio & Claim Workbench
- **Grounded Manuscript Writing**: Synthesizes verified manuscripts with real in-text citations.
- **Split-Screen Studio Canvas**: Draft manuscripts with an interactive evidence drawer to cite cart papers with a single click.
- **Claim Verification Workbench**: Validates empirical claims against literature with consensus meters (Supported / Contradicted / Nuanced).
- **R&R Overhaul Engine**: Generates Point-by-Point Author Response Letters for peer review revisions.

### 4. 🛡️ Pre-Submission Bibliography Verifier & Hallucination Auditor
- **Flexible Citation Ingestion**: Paste unformatted bibliographies, numbered lists (`[1]`), APA strings, or drag-and-drop `.txt` and `.bib` files.
- **Multi-Registry Fuzzy Verification**: Cascading lookup across Crossref, OpenAlex, Europe PMC, and arXiv with Dice-Jaccard string similarity and year-diff scoring.
- **AI Hallucination Sentinel**: Flags fabricated or nonexistent citations generated by LLMs ($<55\%$ confidence score).
- **Discrepancy Inspector**: Identifies year typos, author misspellings, and volume/page errors with 1-click **Apply Auto-Fix**.
- **Dual-Mode Word Export**: Export publication-ready bibliographies with authentic hanging indents or color-coded Verification Audit Reports.

## 🚀 Quick Start (Local Development)

```bash
# Install dependencies
npm install

# Start local Vite development server
npm run dev

# Run TypeScript check and production build
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub (`git push -u origin main`).
2. On GitHub, navigate to **Settings** $\rightarrow$ **Pages**.
3. Under **Build and deployment** $\rightarrow$ **Source**, select **GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` will automatically build and publish the suite.
