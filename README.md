# ScholarForge Suite: Unified Scholarly Intelligence Platform

**ScholarForge Suite** is a unified, state-of-the-art academic research platform that integrates federated multi-registry extraction, PRISMA 2020 systematic review tracking, scholarly manuscript grounding, and pre-submission bibliography integrity auditing.

Developed by **Professor Babu George**.

---

## 🏛️ The 8 Pillars of ScholarForge Suite

### 1. 🔍 Literature & Federated Multi-Source Extraction
- **Concurrent Federated Queries**: Searches OpenAlex, Europe PMC / PubMed Central, Crossref, Semantic Scholar Graph API, and arXiv Open Archive simultaneously with real-time deduplication.
- **PRISMA 2020 Protocol & Diagram**: Real-time identification counts per database, screening attrition tracking (preprints, missing abstracts, citation thresholds), and 1-click export of publication-ready PRISMA methodology prose.
- **Academic Retraction Sentinel**: Cross-checks Europe PMC, PubMed, and Crossref to alert researchers of retracted publications before citing.
- **Dataset Scientometrics**: Computes dataset $h$-index, citation velocity, citation impact tiers (`🔥 Highly Cited`, `⭐ Influential`, `🌱 Emerging`), and automatic methodology tagging (`#RCT`, `#MetaAnalysis`, `#Survey`).

### 2. ✍️ Grounded Manuscript Studio
- **Grounded Manuscript Writing**: Synthesizes verified manuscripts with real, peer-reviewed in-text citations.
- **Split-Screen Studio Canvas**: Draft manuscripts with an interactive evidence drawer to cite cart papers with a single click.
- **R&R Overhaul Engine**: Generates Point-by-Point Author Response Letters for peer review revisions.
- **Multi-Format Dynamic Citation Styler**: APA 7th, MLA 9, Chicago, IEEE, Vancouver, Harvard, Nature, and BibTeX.

### 3. ⚖️ Empirical Claims Workbench
- **Linguistic Claim Extraction**: Identifies factual, empirical claims within draft manuscripts or theses.
- **Multi-Source Validation**: Validates empirical claims against literature with visual consensus meters (Supported / Contradicted / Nuanced).
- **One-Click Studio Promotion**: Directly injects verified evidence into the Manuscript Studio.

### 4. 🛡️ Pre-Submission Bibliography Verifier & Hallucination Auditor
- **Flexible Citation Ingestion**: Paste unformatted bibliographies, numbered lists (`[1]`), APA strings, or drag-and-drop `.txt` and `.bib` files.
- **Multi-Registry Fuzzy Verification**: Cascading lookup across Crossref, OpenAlex, Europe PMC, and arXiv with Dice-Jaccard string similarity and year-diff scoring.
- **AI Hallucination Sentinel**: Flags fabricated or nonexistent citations generated by LLMs ($<55\%$ confidence score).
- **Discrepancy Inspector**: Identifies year typos, author misspellings, and volume/page errors with 1-click **Apply Auto-Fix**.

### 5. 👥 Scholars & Reviewer Network
- **Academic Reviewer & Expert Matching**: Pinpoints peer reviewers, co-authors, and grant panelists using OpenAlex graph queries.
- **Author Scientometrics**: Computes $h$-index, $g$-index, $e$-index, $m$-quotient, co-author networks, and Conflict of Interest (COI) detection.
- **Automated Outreach**: Generates customized invitation letters for peer review and collaborations.

### 6. 🎯 Journal Sentinel & Desk-Rejection Pre-Flight
- **Scopus Journal Matchmaking**: Evaluates manuscript fit across CiteScore, acceptance rate, review speed, Diamond/Gold OA, and APC costs.
- **Desk-Rejection Pre-Flight Audit**: Audits abstract word limits, citation recency percentages, data availability statements, and ethics compliance.

### 7. 🧭 Methodology & Analysis Compass
- **Epistemic Coherence Validator**: Maps 6 research layers: Ontology $\to$ Epistemology $\to$ Paradigm $\to$ Methodology $\to$ Method $\to$ Analysis.
- **Guided Decision Wizard & Code Compendium**: Provides interactive questionnaires and ready-to-run R, Python, and SPSS code blocks.

### 8. 📊 Synthetic Data Forge & Applied Simulation
- **Quantitative Monte Carlo Engine**:
  - **Moderation / Interaction**: $Y = \beta_0 + \beta_1 X + \beta_2 W + \beta_3 (X \times W) + \epsilon$, with Aiken & West mean-centering option and Johnson-Neyman compatibility.
  - **Mediation (Hayes Process Model 4)**: $X \to M \to Y$, path $a$, path $b$, direct effect $c'$, and indirect effect $a \times b$.
  - **Latent SEM / CFA Scales**: Multi-item Likert scales (1-5, 1-7) with Cronbach's $\alpha \ge .80$ and target factor loadings ($\lambda = 0.70-0.88$).
  - **2x2 Factorial ANOVA / ANCOVA**: Treatment vs. Control factorial designs with Cohen's $d$, Partial $\eta^2$, and continuous baseline covariates.
  - **Logistic Regression**: Binary outcomes with target Odds Ratios ($OR = \exp(\beta)$) and logit probability links.
  - **Longitudinal / Panel**: Repeated measurement waves with $\text{AR}(1)$ autocorrelation and random growth intercepts.
  - **Applied Statistician Realism**: Configurable missingness (MCAR / MAR) and outlier contamination injection.
- **Live Statistical Diagnostics & Verification**:
  - In-browser computation of descriptives (Mean, SD, Skewness, Kurtosis), Pearson correlation matrix with significance flags, OLS regression with $t$-statistics and $p$-values, Cronbach's alpha scale reliabilities, and hypothesis confirmation badges.
- **Qualitative Empirical Discourse Engine**:
  - Synthesizes authentic semi-structured in-depth interview transcripts and focus group multi-party dialogues.
  - Generates purposive participant personas and Braun & Clarke thematic codebook matrices (Theme $\to$ Sub-theme $\to$ Definition $\to$ Anchor Exemplar Quotes).
- **Multi-Format Applied Statistician Exporters**:
  - Clean CSV and JSON downloads.
  - Executable R Script (`.R`) with `tidyverse`, `psych`, `ggplot2`, and `interactions`.
  - Python Script (`.py`) with `statsmodels` and `pandas`.
  - IBM SPSS Syntax (`.sps`) with `DESCRIPTIVES`, `CORRELATIONS`, and `REGRESSION`.
  - APA-Style Variable Codebook & Data Dictionary (`.md`).
  - Word Document (`.doc`) for NVivo / ATLAS.ti / MAXQDA qualitative analysis.
- **AI Prompt Synthesizer**:
  - Natural language research design parser (via Google Gemini or private WebLLM WebGPU) translating free-form prompts into verified mathematical specifications.

## 🚀 Quick Start (Local Development)

```bash
# Install dependencies
npm install

# Start local Vite development server
npm run dev

# Run TypeScript check and production build
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub (`git push -u origin main`).
2. On GitHub, navigate to **Settings** $\rightarrow$ **Pages**.
3. Under **Build and deployment** $\rightarrow$ **Source**, select **GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` will automatically build and publish the suite.
